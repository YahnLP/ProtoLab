# ProtoLab

Laboratoire pédagogique des protocoles réseau (Bac Pro CIEL / BTS SIO SISR) : un fichier HTML unique, sans dépendance, qui fonctionne hors ligne.

- 31 protocoles : ARP, VLAN 802.1Q, STP, 802.1X/RADIUS, IP, ICMP, UDP, TCP, DNS, DHCP, NTP, HTTP, HTTPS, TLS/SSL, FTP, Telnet, SSH, SMTP, POP3, IMAP, LDAP, SMB, RDP, SNMP, Syslog, Kerberos, IPsec, WireGuard, SIP/RTP, MQTT, Modbus TCP.
- Simulation saut par saut : diffusion, TTL, NAT, adresses MAC par lien, perte de paquets.
- Niveaux CIEL (20 protocoles, essentiel et quiz) et SISR (31, filtres Wireshark, pannes, sécurité).
- Deux vues : Réseau (animation) et Séquence (diagramme de séquence).
- Adresses fictives uniquement (documentation RFC 5737).
- Contenu des niveaux : proposition, à valider.
