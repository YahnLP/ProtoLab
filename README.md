# ProtoLab

Laboratoire pédagogique des protocoles réseau (Bac Pro CIEL / BTS SIO SISR) : un fichier HTML unique, sans dépendance, qui fonctionne hors ligne.

- 14 protocoles : IP, ICMP, DHCP, UDP, TCP, DNS, HTTP, HTTPS, TLS/SSL, SSH, FTP, SMTP, POP3, IMAP.
- Simulation saut par saut : diffusion, TTL, NAT, adresses MAC par lien, perte de paquets.
- Niveaux CIEL (12 protocoles, essentiel et quiz) et SISR (14, filtres Wireshark, pannes, sécurité).
- Adresses fictives uniquement (documentation RFC 5737).
- Contenu des niveaux : proposition, à valider.
